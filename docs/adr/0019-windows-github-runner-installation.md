# ADR 0019: Windows GitHub Runner Installation

## Status

Accepted.

## Decision

The v0.1 Windows installer accepts only `actions-runner-win-x64-2.337.0.zip`, exactly 103,528,051 bytes with SHA-256 `1150692afa94e71f872017e254ea55b6eece1eece3fe7e3a6d4c93d0a1b85cfc`. Archive paths, formats, sizes, links, devices, aliases, collisions, runtime-state roots, CRCs, and expanded bytes are checked before or during create-new extraction.

The fixed sibling runner root is protected by an exact SYSTEM/Administrators/control DACL; execution identity is absent. Files are opened without sharing, reparse points and hard-linked files are rejected, and rollback removes only transaction-recorded objects. State generated by configuration is re-enumerated, sealed to the same DACL, and recorded before use.

Registration requires an opaque receipt for one syntactically strict private GitHub repository plus separate short-lived registration and removal tokens. `Runner.Listener.exe` is launched directly with fixed arguments, no `cmd.exe`, no `--runasservice`, no `--replace`, no inherited environment, and no token in argv. The token exists only in a mutable UTF-16 `ACTIONS_RUNNER_INPUT_TOKEN` environment block that is cleared after `CreateProcessW`. A suspended process is assigned to a kill-on-close job before resume; output, time, handles, and cleanup are bounded and output is discarded.

The runner service is create-new, never started by installation, and has a fixed executable, service-name argument, broker dependency, control-account logon, automatic final start type, bounded restart policy, and exact SYSTEM/Administrators service DACL. The control password is converted directly from mutable bytes for `CreateServiceW`, cleared immediately, and never stored in the plan or service query model.

Every post-launch failure attempts remote removal with the independent removal token before local runner storage rollback. Commit clears both token copies and finalizes runner registration/storage before account/root ownership is released.

## Evidence limits

Ordinary tests use synthetic processes and storage. The audited official ZIP has been downloaded and passed exact size/SHA, metadata, and full streaming extraction checks. Real repository registration, elevated SCM/account mutation, service start, effective execution-identity denial, and uninstall remain isolated-host gates; no active public workflow targets this runner.
